### Hello 👋

This is my personal portfolio site, built with **React**, powered by **Next.js**, and written in **TypeScript**.

•••

### 🌐 Live

🔗 [https://www.wiola.dev](https://www.wiola.dev/)

•••

### 🛠 Tech Stack

- **Frontend**: React (via Next.js)
- **Language**: TypeScript
- **Styling**: CSS Modules
- **Tooling**: ESLint, Prettier

•••

### 🧪 Getting Started

```bash
git clone https://github.com/w-gluza/portfolio
cd portfolio
npm install
npm run dev
```

Other scripts:

```bash
npm run build
npm run start
npm run lint
npm run typecheck
npm run format
```
